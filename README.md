# Cat_Grep // adelinan   

## Описание 

Проект представляет собой реализацию стандартных утилит cat и grep на языке C.

## Инструкция по запуску 

1. Чтобы запустить программу необходимо загрузить весь репозиторий к себе. 
2. Перейти в соответствующую папку. 
3. Запустите Makefile, цель ```all``` установит программу.
4. Помимо этого вы можете очистить временные файлы целью ```clean```.
5. Также после сборки программы вы можете запустить тесты, выполнив скрипт ```tester_cat.sh``` или ```tester_grep.sh```.
6. После выполнения цели ```make[цель]``` исполняемый файл появится в папке.

## Инструкция по эксплуатации 

| Флаг | Название              | Описание                                                                 |
|------|------------------------|--------------------------------------------------------------------------|
| -b   | number-nonblank        | Нумерует только непустые строки. Игнорирует пустые строки.              |
| -e   | show-ends + show-nonprinting | Отображает символ конца строки как `$` и непечатаемые символы в виде `^` или `M-`. |
| -n   | number-all             | Нумерует все строки, включая пустые. Работает только если `-b` не задан. |
| -s   | squeeze-blank          | Удаляет повторяющиеся пустые строки (оставляет не более одной подряд).   |
| -t   | show-tabs + show-nonprinting | Отображает символ табуляции как `^I` и непечатаемые символы.           |
| -v   | show-nonprinting       | Отображает непечатаемые символы в читаемом формате (`^`, `M-`, и т.п.).  |
| -E   | show-ends              | Показывает символ конца строки как `$`.                                 |
| -T   | show-tabs              | Показывает символ табуляции как `^I`.
